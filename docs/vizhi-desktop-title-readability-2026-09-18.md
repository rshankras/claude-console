The owner's Dashboard.jpg shows that the first conversation title wraps into four lines, with a
partial final word. The Ready bar also competes with the title. The earlier short synthetic names
did not expose this problem.

## Plan

1. Replace character-count wrapping with actual font measurements. Keep a consistent 13.5 px font
   on a 90 px key, an 18 px line pitch, two lines when the title fits and at most three otherwise.
   Prefer whole-word truncation on the last line; keep Unicode graphemes intact.
2. Draw each measured line once. The SDK's `BitmapBuilder.DrawText` performs another wrap inside
   each line rectangle, which produced the unexpected fourth line. The desktop renderer uses the
   same host-provided font and graphics engine, with explicit baseline positioning and clipping.
3. Make the footer 16 px high (previously about 23 px), with 11 px status text. Ready uses a darker
   neutral bar. Thinking, approval and completion retain their existing explicit words and colors.
4. Use the existing display-only alias configuration for confirmed full titles. The proposed
   labels are Organize chats, Plate duration, and Next work plan. Do not guess the full first title,
   whose end is not visible in the photo. Unmapped titles still benefit from the measured renderer.
5. Render both long titles and short labels with the real DLL, test actual pixel bands and measured
   widths, run the full suite, verify the package excludes host graphics dependencies, and install.

Home and All Chats share the same renderer. Original titles remain the sole navigation identity;
no conversations are renamed and no profile bindings change. Terminal-product rendering is unchanged.

The SkiaSharp reference is **compile-only** in the product. The host already supplies this dependency
for PluginApi. Tests and the isolated preview tool supply their own runtime; no managed/native Skia
dependency is included in the distributable plugin.

## Alias configuration

`~/.claude/claude-console/desktop-conversation-labels.json` maps exact full titles to short display
names separately for ChatGPT and Codex. Duplicate aliases fall back to full titles. Configuration
is read at plugin startup. Existing user mappings must be preserved when installing these aliases.

The first full title is pending the owner's answer. The preview's “Organize recent ChatGPT
discussions” is a synthetic completion used to reproduce the layout problem, not a verified title.
